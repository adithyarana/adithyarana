## Selected projects

### 🤖 [Shellix AI](https://shellix.vercel.app/)
**A Python terminal assistant for Linux commands and reviewable code fixes.**

Transforms natural-language requests into commands with explanations and local pattern-based risk checks. Includes confirmation for higher-risk commands, explicit consent before sharing eligible project files, and diff review before applying proposed fixes.

**Built with:** Python · Typer · Rich · prompt-toolkit · Pydantic · HTTPX · OpenRouter API

[Website](https://shellix.vercel.app/) · [Source code](https://github.com/adithyarana/Shellix) · [PyPI package](https://pypi.org/project/shellix-ai/)

### 🏢 [CoreDesk](https://coredesk.store/)
**CRM and business operations, connected in one platform.**

Connects customer and lead management with quotations, sales orders, invoicing, payment allocation, purchasing, and employee operations. Includes multi-warehouse inventory, stock ledgers, configurable permissions, and real-time notifications.

**Built with:** React · Next.js · Node.js · Express · PostgreSQL · Prisma · Socket.IO · JWT

[Visit CoreDesk](https://coredesk.store/)

### 🍽️ [Restroo](https://restroo.in/)
**Restaurant operations with a unified dashboard.**

Brings order management, billing, inventory, and staff workflows together for cafés, cloud kitchens, and restaurants. Features QR ordering, dine-in/takeaway/delivery workflows, and POS billing.

**Built with:** Node.js · React · PostgreSQL · REST APIs · WebSockets

[Visit Restroo](https://restroo.in/)

### 💳 FinTech Payment Automation Platform
**Crypto payment processing and transaction lifecycle management.**

Built TRON wallet generation and USDT TRC20 monitoring, real-time transaction updates, payment verification, automated fund sweeping, and withdrawal workflows with retry logic.

**Built with:** Node.js · Express · PostgreSQL · WebSockets
